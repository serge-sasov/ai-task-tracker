### Общие элементы (на всех экранах)

- **Левый сайдбар** с 5 пунктами навигации (Задачи / Поиск / Календарь / Токены / Управление данными) — активный пункт выделен.
- **Шапка**: заголовок раздела + (опционально) строка AI-поиска (Q-UX-2 — дефолт только раздел S-03).
- **Обновление данных**: polling UI (интервал ≤ 5 мин, Q-001) или по возвращении на экран; индикатор «обновлено HH:MM:SS».

## 2. Состояния UI (состояние/пусто/ошибка/загрузка)

Обязательные состояния для каждого раздела (R-028: «нет данных», «источник недоступен», «AI-поиск недоступен» — явные, на русском).

| Экран | Загрузка | Пусто | Успех | Ошибка |
|---|---|---|---|---|
| S-01 | Скелетон списка | «Задач пока нет. Данные будут импортированы автоматически после синхронизации opencode.» | Таблица задач | «Не удалось загрузить задачи» + «Повторить»; или баннер «Источник данных (opencode) недоступен» |
| S-02 | Скелетон деталей | — (задача существует) | Заполненная карточка; при отсутствии решений — «Решений не зафиксировано» (UC-E2E-003 S7) | «Не удалось загрузить детали задачи» + «Повторить» + «Назад к списку» |
| S-03 | Индикатор поиска («Ищем по задачам…», до 15 с) | «Ничего не найдено. Попробуйте изменить запрос.» (в т.ч. нерелевантный запрос — честная пустая выдача) | Список top-K ≥ 5 с обоснованием | «AI-поиск недоступен: LLM не отвечает. Попробуйте позже.» (приложение работает) |
| S-04 | Скелетон сетки | «Нет задач в выбранном периоде.» (пустой период — не ошибка) | Сетка с задачами + продолжительностью | «Не удалось загрузить календарь» + «Повторить» |
| S-05 | Скелетон таблицы | «Нет данных за выбранный период.» | Таблица моделей + итог; модель без использования — 0 или «нет данных» | «Не удалось построить сводку по токенам» + «Повторить» |
| S-06 | Кнопка в состоянии загрузки | «Данных для удаления нет.» | «История удалена.» + все разделы в пустых состояниях | «Не удалось удалить историю. Повторите попытку.» (без «полудаления») |

Правила:
- Пустое состояние ≠ ошибка: у каждого своё RU-текст и иконка/иллюстрация.
- Ошибка всегда имеет кнопку «Повторить» (кроме S-06 E2 — no-op).
- Загрузка — не больше 15 с (R-023); затем переход в состояние ошибки.
- Все состояния — без белых страниц, с видимым заголовком раздела (R-028, UC-E2E-001 S4).

## 3. Доступность (a11y)

Минимальный набор (WCAG 2.1 AA) — обязательный для приёмки:

- **Контраст**: текст ≥ 4.5:1, крупные элементы ≥ 3:1 (WCAG 1.4.3).
- **Фокус**: видимый фокус-индикатор на всех интерактивных элементах (WCAG 2.4.7); не убирать `outline`.
- **Клавиатура**: всё управление (навигация, поиск, переключение режимов календаря, подтверждение удаления) — с клавиатуры (Tab/Enter/Space/Arrow); порядок фокуса логичный (WCAG 2.1.1).
- **Экраны**: `aria-label` для кнопок с иконками, `role="alert"` для ошибок, `aria-live="polite"` для обновления данных (polling) (WCAG 4.1.3).
- **Формы**: label связан с input (S-03: «Поиск по задачам»); ошибка валидации — рядом с полем (UC-E2E-004 E2).
- **Диалоги**: `role="dialog"`, `aria-modal="true"`, фокус в диалоге при открытии, возврат фокуса на кнопку после закрытия (S-06).
- **Таблицы**: `scope="col"`/`scope="row"`, заголовки столбцов (S-01, S-05).
- **Статусы задач**: не только цветом — текст + иконка (WCAG 1.4.1).
- **Язык**: `<html lang="ru">` (R-030).
- **Масштабирование**: корректная вёрстка при zуме до 200% (WCAG 1.4.4).
