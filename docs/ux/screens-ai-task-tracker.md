### Общие элементы (на всех экранах)

- **Левый сайдбар** с 5 пунктами навигации (Задачи / Поиск / Календарь / Токены / Управление данными) — активный пункт выделен.
- **Шапка**: заголовок раздела + (опционально) строка AI-поиска (Q-UX-002 — дефолт только раздел S-03).
- **Обновление данных**: polling UI (интервал ≤ 5 мин, Q-001) или по возвращении на экран; индикатор «обновлено HH:MM:SS».

### Колонка «Модель» (R-014)

- Порядок столбцов: **Название | Модель | Дата | Продолжительность | Статус**; колонка «Модель» идёт сразу после «Название».
- Основная модель — модель с максимальной суммой input + output + cache tokens по задаче.
- Если моделей несколько, рядом с основной показывается видимый индикатор `+1`/`+N`.
- Полный упорядоченный список моделей доступен в tooltip и в доступном имени (`aria-label` ячейки), не только по hover.
- Если usage нет, в ячейке отображается «Нет данных».
- Длинное имя модели обрезается с ellipsis; полное имя и список — в tooltip; ширина таблицы не ломается.

### Колонка «Модель» в дневном виде S-04 (R-015)

- В режиме «День» (`/calendar/:date`) таблица задач имеет колонку «Модель» сразу после «Задача»; порядок остальных колонок: Начало, Окончание, Продолжительность, Статус.
- Правила ячейки **идентичны S-01 (R-014)** и не дублируют его (R-015 ограничена только S-04):
  - основная модель (первый элемент `models`);
  - если моделей больше одной — видимый индикатор `+N`;
  - полный упорядоченный список — в `title` и `aria-label` ячейки (не только по hover);
  - если `models` пуст — «Нет данных».
- Термины и метки те же, что в S-01: «Модель» (заголовок) и «Нет данных» (пусто). Порядок и tie-break — те же, что R-014 (total tokens desc, tie-break по имени модели).
- Дневной вид S-04 — только чтение: колонка «Модель» не добавляет новых взаимодействий сверх tooltip/`aria` поведения S-01.

| Экран | Загрузка | Пусто | Успех | Ошибка |

| Экран S-03 · AI-поиск | Индикатор поиска («Ищем по задачам…», до 15 с) | «Ничего не найдено. Попробуйте изменить запрос.» (в т.ч. нерелевантный запрос — честная пустая выдача) | Список top-K ≥ 5 с обоснованием | «AI-поиск недоступен: LLM не отвечает. Попробуйте позже.» (приложение работает) |
| Экран S-04 · Календарь | Скелетон сетки | «Нет задач в выбранном периоде.» (пустой период — не ошибка); в режиме «Год» месяцы без данных — «Нет данных» | Сетка с задачами + продолжительностью; «Месяц» — полная сетка по неделям (Пн–Вс, все дни); «Год» — 12 месяцев со статистикой; режим «День» — таблица с колонкой «Модель» (primary / `+N` / `title`+`aria-label` / «Нет данных», R-015, те же правила что S-01) | «Не удалось загрузить календарь» + «Повторить» |
| Экран S-05 · Токены | Скелетон таблицы | «Нет данных за выбранный период.» | Таблица моделей + итог; модель без использования — 0 или «нет данных» | «Не удалось построить сводку по токенам» + «Повторить» |
| Экран S-06 · Управление данными | Кнопка в состоянии загрузки | «Данных для удаления нет.» | «История удалена.» + все разделы в пустых состояниях | «Не удалось удалить историю. Повторите попытку.» (без «полудаления») |

Правила:
- Пустое состояние ≠ ошибка: у каждого своё RU-текст и иконка/иллюстрация.
- Ошибка всегда имеет кнопку «Повторить» (кроме S-06 E2 — no-op).
- Загрузка — не больше 15 с (R-023); затем переход в состояние ошибки.
- Все состояния — без белых страниц, с видимым заголовком раздела (R-028, UC-E2E-001 S4).

## 3. Доступность (a11y)

Минимальный набор (WCAG 2.1 AA) — обязательный для приёмки:

- **Контраст**: текст ≥ 4.5:1, крупные элементы ≥ 3:1 (WCAG 1.4.3).
- **Фокус**: видимый фокус-индикатор на всех интерактивных элементах (WCAG 2.4.7); не убирать `outline`.
- **Клавиатура**: всё управление (навигация, поиск, переключение режимов календаря, подтверждение удаления) — с клавиатуры (Tab/Enter/Space/Arrow); порядок фокуса логичный (WCAG 2.1.1).
- **Экраны**: `aria-label` для кнопок с иконками, `role="alert"` для ошибок, `aria-live="polite"` для обновления данных (polling) (WCAG 4.1.3).
- **Формы**: label связан с input (S-03: «Поиск по задачам»); ошибка валидации — рядом с полем (UC-E2E-004 E2).
- **Диалоги**: `role="dialog"`, `aria-modal="true"`, фокус в диалоге при открытии, возврат фокуса на кнопку после закрытия (S-06).
- **Таблицы**: `scope="col"`/`scope="row"`, заголовки столбцов (S-01, S-05); ячейка «Модель» имеет `title` и `aria-label` с полным упорядоченным списком моделей (S-01: R-014; S-04 дневной вид: R-015, те же правила).
- **Статусы задач**: не только цветом — текст + иконка (WCAG 1.4.1).
- **Язык**: `<html lang="ru">` (R-030).
- **Масштабирование**: корректная вёрстка при zуме до 200% (WCAG 1.4.4).
