Каталог сценариев

Статический UX-прототип T-005 / U-02 (AI Task Tracker). Каждый сценарий — отдельная страница со всеми состояниями (загрузка / пусто / успех / ошибка). Данные — фикстуры, без сети и хранения.

UC-E2E-001 · Приложение с пустым каталогом

Новый запуск: все разделы показывают честные пустые состояния, без ошибок и «выдуманных» данных.

Открыть сценарий

UC-E2E-002 · Каталог opencode недоступен

Ошибочное состояние списка: баннер «Источник данных (opencode) недоступен» и кнопка «Повторить».

Открыть сценарий

UC-E2E-003 · Задачи в списке и карточка деталей

Таблица задач (5 фикстур) с колонкой «Модель» (основная модель, «+1», «Нет данных»), карточка задачи: действия, решения, токены. Включая «Решений не зафиксировано».

Открыть сценарий

UC-E2E-004 · AI-поиск по задачам

Поиск с валидацией пустого запроса, «Ищем по задачам…», top-K = 5, честная пустая выдача, ошибка LLM.

Открыть сценарий

UC-E2E-005 · Календарь задач

Режимы День/Неделя/Месяц/Год, навигация периода, загрузка (скелетон сетки), полная сетка месяца (Пн–Вс), год со статистикой по месяцам (месяц с данными — кнопка «Открыть месяц»), полосы задач с продолжительностью, пустой период.

UC-E2E-006 · Статистика по токенам

Таблица по моделям (qwen3.8:27b, llama3.1:8b), «Всего токенов», периоды: всё время / 10.11 / 11.11.

UC-E2E-007 · Обновление данных без дублей

Повторная синхронизация: данные обновляются, дублей нет, индикатор «обновлено HH:MM:SS».

Открыть сценарий

UC-E2E-008 · Удаление истории

Кнопка «Удалить историю», диалог подтверждения с предупреждением, «История удалена.», повторное удаление — no-op.
