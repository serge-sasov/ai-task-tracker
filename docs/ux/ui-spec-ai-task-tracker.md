## 1. Personas and goals

| Persona | Goal | Key scenarios |
|---|---|---|
| P-1 — Локальный разработчик (основная) | Понять, что делалось по задачам: действия, решения, токены; видеть задачи на календаре с продолжительностью; находить задачи AI-поиском; контролировать токены по моделям | UC-E2E-003, UC-E2E-004, UC-E2E-005, UC-E2E-006, UC-E2E-008 |
| P-2 — Наблюдатель / QA (вторичная) | Убедиться, что стек поднимается, данные импортируются без дублей, UI корректно показывает пустые/ошибочные состояния (без белых страниц) | UC-E2E-001, UC-E2E-007 |

Контекст: single-user, localhost, без аутентификации (Q-004, R-027); язык UI — русский (Q-006, R-030).

## 6. Accessibility and UI copy

Доступность (WCAG 2.1 AA, обязательный минимум для приёмки):
- `<html lang="ru">`; семантическая разметка (main, nav, table, dialog).
- Видимый focus-индикатор на всех интерактивных элементах; порядок фокуса логичный; всё управление — с клавиатуры (Tab/Enter/Space/Arrow).
- Контраст: текст ≥ 4.5:1, крупные элементы ≥ 3:1.
- Статусы задач — текст + иконка (не только цветом).
- `role="alert"` для ошибок; `aria-live="polite"` для индикатора обновления и статусов загрузки.
- Label связан с input (S-03); ошибка валидации — рядом с полем.
- Диалог S-06: `role="dialog"`, `aria-modal="true"`, фокус при открытии и возврат после закрытия.
- Таблицы S-01/S-05: `scope="col"`/`scope="row"`; масштабирование до 200% без потери вёрстки.

Канонический RU-копирайтинг — `docs/ux/screens-ai-task-tracker.md` §4 (используется как есть). Статусы задач: «Завершена» / «Прервана» / «Не завершена» (Q-008).

Разметка прототипа:
- Breakpoint: 960px — сайдбар превращается в верхнюю навигацию (одна колонка); < 600px — таблицы в карточные строки.
- Макс. ширина контента — 1200px; сетка календаря «Неделя» и «Месяц» — 7 колонок; сетка «Год» — 4 колонки × 3 ряда (12 месяцев).
- Только локальные ассеты (`assets/app.css`, `assets/app.js`), relative links, без CDN/сетевых вызовов; шрифты системные; иконки — inline SVG / CSS-фигуры.
