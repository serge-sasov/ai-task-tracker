## Model-cell rules (from ui-spec / contracts CLS-005)
- Props: `models: string[]`, optional `labelPrefix` for aria-label ("Модель"/"Модели").
- Primary = `models[0]` (API order; ordering is a backend rule, the cell just uses the list). When empty → «Нет данных».
- When `models.length > 1` → also show `+{{ n-1 }}` badge.
- `title` and `aria-label` = full ordered list: empty → «Модель: Нет данных»; else «Модель: m1, m2, …».
- Long names ellipsis (CSS `overflow:hidden; text-overflow:ellipsis; white-space:nowrap`); full value stays in title/aria.
- No new ordering/tie-break rule in the component (backend already orders by API-001).
